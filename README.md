# Redthread

Redthread is a skills-only plugin for ChatGPT and Codex. It turns one user-supplied portrait into a polished 3:4 two-panel editorial collage with a repeated subject, source-derived paper palette, bilingual hand-lettering, and a wine-red pencil connector.

## Install from this repository

Until the plugin is approved for the universal plugin directory, install the standalone skill with:

`Use $skill-installer to install https://github.com/HuHana77/redthread from path skills/redthread with the name redthread.`

## Use

Attach one portrait and ask:

`Use $redthread to turn this portrait into a red-thread dual-scene collage.`
